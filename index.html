Acerca del Sistema POS
Sistema de Punto de Venta - Ferretería San José

Sistema desarrollado para la gestión integral de una ferretería con las siguientes características:

  • Ventas con y sin conexión a internet
  • Control de inventario con alertas automáticas
  • Gestión de múltiples usuarios con permisos
  • Reportes de ventas y ganancias
  • Corte de caja diario
  • Importación de productos desde Excel

Versión: 1.0

Tecnologías: HTML5, CSS3, JavaScript, Bootstrap 5, PWA
